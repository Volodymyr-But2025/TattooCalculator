# Tattoo Calculator — калькулятор ціни тату

PWA для тату-майстра: оцінка вартості сеансу за розміром, стилем, кольором і зоною на тілі, з копіюванням комерційної пропозиції клієнту.

**Live:** [https://tattoo-calculator-ashen.vercel.app/](https://tattoo-calculator-ashen.vercel.app/)  
**GitHub:** [Volodymyr-But2025/TattooCalculator](https://github.com/Volodymyr-But2025/TattooCalculator)

## Що вміє

- **Розмір** — ширина × висота (см) зі слайдерами та числовими полями.
- **Складність** — множники стилю, кольору та місця на тілі.
- **Рейт майстра** — ставка за годину і розхідники зберігаються в `localStorage`.
- **Розрахунок** — орієнтовний час, базова ціна, знижка, діапазон ±10%.
- **Мінімум для кольору** — нижня межа ціни для кольорових робіт.
- **Копіювання** — текст пропозиції клієнту в буфер обміну (українською).
- **PWA** — встановлюваний застосунок через `vite-plugin-pwa` (тост при новій версії).

## Встановлення на телефон

Відкрий live у браузері телефону: [tattoo-calculator-ashen.vercel.app](https://tattoo-calculator-ashen.vercel.app/).

### Android (Chrome)

1. Відкрий сайт у **Chrome**.
2. Натисни меню **⋮** (три крапки) праворуч угорі.
3. Обери **«Додати на головний екран»** / **«Install app»** / **«Встановити застосунок»**.
4. Підтверди — на домашньому екрані з’явиться іконка **«Тату Кальк»**.

Якщо пункту немає: у адресному рядку може бути іконка встановлення (⊕ / download) — натисни її.

### iOS (Safari)

1. Відкрий сайт у **Safari** (не Chrome — на iOS PWA додається через Safari).
2. Натисни кнопку **«Поділитися»** (квадрат зі стрілкою вгору).
3. Прокрути меню й обери **«На екран „Додому“»** (англ. **Add to Home Screen**).
4. За потреби змініть назву й натисни **«Додати»**.

Після цього калькулятор відкривається як окремий застосунок (без адресного рядка браузера). Оновлення підтягуються з мережі; якщо з’явиться тост «Доступна нова версія» — натисни **«Оновити»**.

## Стек

| Шар | Технології |
| --- | --- |
| UI | React 19, Vite, Tailwind CSS |
| Логіка | чиста JS-формула (`calculateQuote.js`) |
| Зберігання | `localStorage` для параметрів рейту |
| PWA | `vite-plugin-pwa`, Workbox |
| Деплой | [Vercel](https://tattoo-calculator-ashen.vercel.app/) |

## Запуск

```bash
npm install
npm run dev
```

Відкрий [http://localhost:5173](http://localhost:5173).

```bash
npm run build     # production-збірка
npm run preview   # перегляд dist
npm run lint      # ESLint
npm run icons     # перегенерація PWA-іконок з SVG
```

## Структура

```
src/
  App.jsx              # UI і потік розрахунку
  calculateQuote.js    # формула ціни та множники опцій
  quoteText.js         # текст пропозиції клієнту + формат грошей
  settingsStorage.js   # збереження ставки та розхідників
  registerPwa.js       # реєстрація service worker
  index.css            # точка входу Tailwind
public/                # іконки PWA і ассети маніфесту
scripts/               # генерація іконок
```
